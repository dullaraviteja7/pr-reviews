# GitHub PR Review Analysis Dashboard

## Project Overview

This project provides a suite of Python scripts to analyze GitHub Pull Request (PR) reviews. It fetches PR data, including review comments, from a specified GitHub repository. These comments are then analyzed using an AI model (via Hugging Face Inference API) to determine their category and severity, and to generate a suggested developer guideline. Finally, a web-based dashboard built with Plotly Dash visualizes these analyses, offering insights into code review patterns, comment types, and reviewer contributions.

## Features

*   **Data Extraction**: Fetches PR details, authors, reviewers (including Code Owners), and review comments from a GitHub repository.
*   **AI-Powered Analysis**: Classifies review comments by category (e.g., Logic Error, Code Style) and severity (High, Medium, Low) using a Hugging Face Zero-Shot classification model. Generates template-based developer guidelines.
*   **Caching**: Caches AI analysis results to speed up repeated processing and reduce API calls.
*   **Data Output**: Saves extracted and analyzed data into CSV files.
*   **Interactive Dashboard**: Visualizes key metrics and insights using Plotly Dash, including:
    *   Distribution of comment categories.
    *   Distribution of comment severities.
    *   PRs with the most high-severity comments.
    *   Review load per reviewer.

## Setup Instructions

1.  **Clone the Repository**:
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **Create a Python Virtual Environment** (Recommended):
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Create and Configure `.env` File**:
    *   Create a file named `.env` in the root of the project.
    *   You can copy `.env.example` (if provided, or use the structure below) to `.env`.
    *   Add the following environment variables with your actual credentials:

        ```env
        # For pr_fetcher.py (GitHub Data Extraction)
        GITHUB_TOKEN="your_github_personal_access_token"
        REPO_OWNER="owner_of_the_target_repo"
        REPO_NAME="name_of_the_target_repo"

        # For comment_analyzer.py (Hugging Face AI Analysis)
        HF_TOKEN="your_hugging_face_user_access_token"
        ```
    *   **Obtaining Tokens**:
        *   `GITHUB_TOKEN`: Go to your GitHub settings > Developer settings > Personal access tokens. Generate a new token with `repo` scope.
        *   `HF_TOKEN`: Go to your Hugging Face profile > Settings > Access Tokens. Create a new token with `read` or `write` role (read should be sufficient for inference).

## Workflow / How to Run

The scripts are designed to be run in sequence. By default, `comment_analyzer.py` and `dashboard_generator.py` use sample data located in the `data/` directory.

1.  **Step 1: Fetch Data from GitHub (Optional - if you want fresh/live data)**
    *   This script populates the `data/` directory with CSV files (`pr-list.csv`, `reviews-list.csv`, etc.) from the specified GitHub repository.
    *   Ensure your `.env` file is configured with `GITHUB_TOKEN`, `REPO_OWNER`, and `REPO_NAME`.
    ```bash
    python pr_fetcher.py
    ```
    *   This will create files like `data/pr-list.csv`, `data/reviews-list.csv`, etc.

2.  **Step 2: Analyze Review Comments (Generates `sample-reviews-analysis.csv`)**
    *   This script reads `data/sample-reviews-list.csv` (which is a small, generic sample provided in the repo), analyzes the comments using the AI model, and saves the results to `data/sample-reviews-analysis.csv`.
    *   It also uses `data/ai_analysis_cache.json` to avoid re-analyzing comments.
    *   Ensure your `.env` file is configured with `HF_TOKEN`.
    ```bash
    python comment_analyzer.py
    ```
    *   *Note*: To analyze the actual data fetched by `pr_fetcher.py` (i.e., `data/reviews-list.csv`), you would need to modify `comment_analyzer.py` to point to `data/reviews-list.csv` as its input and potentially a different output file.

3.  **Step 3: View the Dashboard**
    *   This script launches a local web server to display the dashboard.
    *   By default, it loads data from all the `sample-*.csv` files in the `data/` directory.
    ```bash
    python dashboard_generator.py
    ```
    *   Open your web browser and navigate to `http://127.0.0.1:8050/` (or the address shown in your terminal).

## Output

*   **CSV Files (in `data/` directory)**:
    *   `pr-list.csv`: Details of fetched Pull Requests.
    *   `author-list.csv`: List of PR authors.
    *   `reviewer-list.csv`: List of reviewers and their Code Owner status.
    *   `reviews-list.csv`: Raw review comments.
    *   `reviews-analysis.csv` (or `sample-reviews-analysis.csv`): Review comments augmented with AI-derived category, severity, and guidelines.
    *   `ai_analysis_cache.json`: Cached AI analysis results (gitignored).
*   **Interactive Dashboard**: A web page displaying various charts and tables based on the analyzed data.

## Customization (Future Considerations)

*   **Target Repository**: Change `REPO_OWNER` and `REPO_NAME` in `.env` to analyze a different repository.
*   **AI Model**: The AI model for comment analysis (`API_URL_ZERO_SHOT` in `comment_analyzer.py`) can be changed to other Hugging Face zero-shot classification models.
*   **Analysis Categories/Severities**: The predefined lists (`CATEGORIES`, `SEVERITIES`) in `comment_analyzer.py` can be modified.
*   **Guideline Templates**: The `GUIDELINE_TEMPLATES` in `comment_analyzer.py` can be expanded or customized.
